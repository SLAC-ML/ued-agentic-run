Questions for you

None blocks the next step; each one turns a guess in the tools into a fact.

  1. The write path. Now the main blocker. Should stage writes go through Badger routines that an operator approves, as the proposal describes, or through the MCP tools directly with approval and limits? For the accelerator side (gun RF, magnets), from ued-daq or through uedopr on testfac-srv01?
  2. Charge diagnostic (stages 2–3). Which PV gives the bunch charge: a Faraday cup, the Wave8 (UED:W8:01), something else? And which PV drives the FC/Diag YAG inserter? Neither is in the run-7 list.
  3. Sample stage (stages 4–7). The run-7 list puts it on XPS-11 (MMN:11:03/04/05), whose motor descriptions say "Incoupling X/Y" and "Outcoupling". Are those descriptions stale? The list's "2nd SUED sample stage" block gives MMN:03:04 as Z, which is also the pump long delay. Is that block stale?
  4. Correctors (stage 5). Which PV sets the kick, BCTRL (reads −145.6, EGU "kG-m", limits ±521) or BDES (reads 0)? What's the kick per unit?
  5. Pump (stages 6, 8). Is the pump spot steered with the lens H/V (MMN:08:05/06, in the run-7 list) or the SmarAct UED:MCS:01:m7/m8 ("pump_beam_X/Y")? Is MMN:08:01, whose description says "Pump Throttle", unused for SUED? The power meter read "in" on 10-16. Should the tools take it out?
  6. "UV feedback" (stage 3). Is it an existing loop, or should the tool run it?
  7. Operating phase (stage 2). Is it "zero crossing + 37°", as in the May 2025 deck? Which way does PREQ count?
  8. Transmission signal (stage 5). What do operators read to judge transmission (far-detector counts, a charge monitor)? What are the collimator's in and out positions in mm?
  9. Pattern quality and Bragg peaks (stages 7, 8). The Andor image now reads over CA. How is a good pattern judged today, and which Bragg peaks (ROIs) does time zero follow? Where does the Run 6 BOED code live?
